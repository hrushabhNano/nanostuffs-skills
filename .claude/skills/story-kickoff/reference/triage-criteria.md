# Triage criteria

A ticket is **Trivial** only if **all** of the following are true:

- touches a single implementation area
- affects one file, or very few
- no schema change
- no API contract change
- no architectural decision
- no ambiguous requirements
- no cross-module impact

If even one does not hold, it is **Standard/complex**. When unsure, it is Standard/complex.

When reporting a classification, list each criterion as met or not met with a one-line reason.
